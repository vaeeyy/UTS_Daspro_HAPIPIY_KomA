TIXORA: Tickets Online Reservation App

TIXORA adalah program pascal sederhana yang menggambarkan pemesanan tiket konser online 
melalui suatu aplikasi pemesanan untuk efisiensi dan efektivitas, mulai dari pilihan menu beranda pemesanan, 
pemesanan tiket sesuai dengan track list concert, jumlah pembelian dan bukti pemesanan. yang keseluruhannya dapat
diakses pada terminal.

Fitur Utama pada Program

1. if else: Memastikan jumlah tiket yang diinput tidak negatif atau sesuai dengan kondisi pembelian. 
Jika jumlah tiket memenuhi syarat atau lebih dari sama dengan 4 tiket, 
maka akan mendapatkan diskon sebesar 10%, jika tidak maka diskon bernilai 0.   

2. case of: Dari pilihan menu 1-4, user dapat menentukan langkah selanjutnya dari program pemesanan tiket ini 
(1 : Lihat Daftar Konser, 2 : Pesan Tiket, 3 : Lihat Pesanan Terakhir, 4 : Keluar). 
Jika pilihan tidak ada di antara list tersebut, maka program akan menampilkan pesan menu tidak valid.   

3. repeat until: Digunakan untuk menjalankan menu utama secara berulang. 
Setelah selesai menggunakan salah satu menu dan menekan Enter, program akan terus berulang sampai user memilih angka 4 untuk keluar.   

4. for to do: Digunakan untuk menampilkan daftar konser secara berurutan berdasarkan nomor indeks array 
dari 1 hingga jumlah data konser yang tersedia.   

5. continue: Digunakan untuk melewati iterasi tertentu di dalam perulangan. Misalnya, jika ingin melewati proses pemesanan untuk konser tertentu 
yang stoknya kosong, program dapat melompat ke iterasi berikutnya tanpa menghentikan seluruh proses.
